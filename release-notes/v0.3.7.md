- Improved project tabs on macOS: the tab bar now shares the title bar's color, tabs fit their project names instead of stretching across the window, and the active tab is marked with an accent line.
- Improved project tab labels to show the project name instead of the window title. Hovering a tab shows the project's folder, and projects with the same name show their parent folder.
- Added double-click and window dragging on the empty part of the project tab bar on macOS, like the title bar.
