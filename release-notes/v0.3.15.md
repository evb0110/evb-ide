- Added a `typescript.version` setting to choose the TypeScript that powers JavaScript and TypeScript features, for all projects or one project in `.zed/settings.json`. `"auto"` uses the project's own TypeScript, now also when it is installed in a parent folder (a package opened inside a monorepo, or a single opened file) or only in nested packages (pnpm workspaces). Projects without TypeScript get the newest TypeScript 6.x instead of the older 5.9 bundled with vtsls. A version or range such as `"6.0.3"` or `"5.9"` installs and uses that TypeScript, and `"7"` switches TypeScript, TSX and JavaScript files to TypeScript 7's native language server. Changes apply without restarting.
- Added a clear button to search inputs: Find in Files, in-file search and search popups such as Go to File and the command palette show it while they have text.
- Fixed language servers stopping for tabs that had not been shown yet when a settings change restarted another language server.
