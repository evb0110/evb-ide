- Added Windows x64 builds (Windows 10 or later): a portable archive with the app and its command line tool.
- Added working on several projects at once, like WebStorm: each project opens in its own window, and on macOS those windows are tabs of one window. Opening a project that is already open switches to it.
- Added SCSS and Sass highlighting, including `<style lang="scss">` blocks in Vue files: the SCSS extension now installs automatically.
- Improved the interface to name EVB IDE everywhere it named Zed, including dialogs, settings descriptions, permission prompts and command palette entries.
- Improved the About window to show EVB IDE's version, commit, copyright and license.
- Improved the macOS installer: the disk image opens to a laid-out window with an arrow from EVB IDE to Applications.
